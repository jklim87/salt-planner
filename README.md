# 소금의 하루

아기 소금이의 오늘 일정표입니다. 기상 시각을 넣고 시작하면 하루 일정이 자동으로 만들어지고, 링크를 연 모든 기기가 같은 일정을 봅니다. 루틴은 프리셋으로 직접 만들어 저장할 수 있습니다.

**웹앱:** https://jklim87.github.io/salt-planner/

휴대폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 사용할 수 있습니다.

## 프리셋 (2026-09-21 추가)

- 메뉴(⋯)의 **프리셋 만들기**로 들어가면 위에 [시간표로 돌아가기] [프리셋 만들기] 버튼, 아래에 저장된 프리셋 목록(수정·삭제)이 있습니다.
- 만들기 화면에는 현재 기본 루틴 카드가 6:30 기상 기준으로 미리 채워집니다. 카드마다 시작·종료를 고칠 수 있고(시작을 바꾸면 종료가 같은 길이만큼 따라감), 기상과 수유 후 입면을 빼면 삭제할 수 있으며 낮잠·수유·목욕 카드를 추가할 수 있습니다. 카드 머리에 소요시간, 수유에는 수유텀, 낮잠에는 깨시가 표시됩니다. 저장 시 시각 순으로 정렬되고 겹치는 카드가 있으면 저장되지 않습니다.
- **기본 루틴으로 만들기**를 체크해 저장하면 그 프리셋이 "기본 루틴으로 시작"에 쓰이고 목록에 "기본" 배지가 붙습니다.
- 시작 화면의 "기본 루틴으로 시작" 아래에 저장된 프리셋이 "기상 06:30 · 입면 18:30 · 낮잠 3시간 40분 (총 4회)" 요약과 함께 나열되고, 누르면 그 루틴으로 바로 시작합니다.
- 하루를 시작하면 그 시점의 프리셋 내용이 그 날에 저장되므로, 이후 프리셋을 고쳐도 이미 시작한 하루는 바뀌지 않습니다.
- 규칙 엔진은 카드 목록에서 깨시·낮잠 길이·수유 시각·마지막 간격을 읽어 동작하므로 낮잠 개수나 목욕 유무가 다른 프리셋도 같은 규칙으로 보정됩니다. 프리셋이 정한 수유텀이 2:30~3:30을 벗어나면 프리셋 값을 따릅니다.

## 2026-11-11 변경

- **대변 기록.** 시간표 오른쪽 아래에 💩 버튼이 항상 떠 있습니다. 누르면 "소금이 똥 쌌어요?" 확인창이 뜨고, "응"을 누르면 지금 시각으로 "대변" 카드가 시간표에 들어갑니다. 카드를 눌러 시각을 고치거나 지울 수 있고 다른 기기와 동기화됩니다.
- **마지막 세트 길이 고정.** 목욕 15분 → 마지막 수유 10분 → 입면 10분은 빈틈 없이 붙은 한 덩어리입니다. 세 카드는 마지막 수유 시작 하나에서 계산되므로 앞 일정이 바뀌면 시작·종료가 모두 함께 움직입니다. 입면을 따로 기록하던 값(잠든 시각)은 더 이상 쓰지 않습니다.
- 마지막 수유와 입면은 시작이나 종료 어느 쪽을 바꿔도 세트 전체가 같은 폭으로 움직입니다. 목욕은 수정할 수 없고 항상 마지막 수유 직전 15분입니다. 프리셋 편집기도 같은 규칙입니다.

## 2026-10-30 변경

- 시작 시각 하한(6:00)을 없앴습니다. 새벽 4시 시작, 21시 입면 프리셋 모두 그대로 실행됩니다.
- **목욕 → 마지막 수유 → 입면은 한 세트**입니다. 목욕 종료는 마지막 수유 시작, 입면 시작은 마지막 수유 종료에 항상 붙습니다. 프리셋에 틈이 있어도 불러올 때 붙이고, 시간표에서 마지막 수유 시각을 옮기면 목욕과 입면(기록된 잠든 시각 포함)이 같은 폭으로 따라갑니다. 입면 카드는 잠든 시각만 기록합니다.
- 프리셋 편집기: 기상 시각을 바꾸면 모든 카드가 함께 이동합니다. 목욕·마지막 수유·입면은 자리를 옮길 수 없고 마지막 수유는 지울 수 없습니다. 목욕 카드는 시작만 고치며 종료는 마지막 수유 시작에 자동으로 맞춥니다.
- 시간표 맨 아래 "+ 낮잠 추가 / + 수유 추가"로 오늘 일정에 카드를 넣을 수 있고, 낮잠·수유 카드(마지막 수유 제외) 편집창의 "삭제"로 뺄 수 있습니다. 오늘의 카드 목록(프리셋 스냅샷)만 바뀌고 저장된 프리셋은 그대로입니다.

## 2026-10-06 변경

- **수유 후 입면 카드를 수유 ⑤와 입면으로 분리**했습니다. 입면은 마지막 수유 종료 시점부터 10분으로 자동 계산되며 프리셋에서 직접 편집하지 않습니다. 이전 형식의 프리셋은 자동으로 변환됩니다(수유 10분 + 입면 10분).
- **수유 카드에 목표 조유량(ml)**을 넣을 수 있고, 시간표에 "수유텀 3:00 / 목표: 180ml"처럼 표시됩니다. 보조 표기 사이 구분자는 " / "입니다.
- **프리셋 편집기의 ▲▼ 이동은 자리만 바꿉니다.** 시각은 그대로 두고, 저장할 때 순서와 시각이 맞는지 검사합니다.

## 동작 규칙 (2026-09-15 개정)

- **기상과 수유①은 별도 카드**입니다. 기상 카드는 시각 하나만 가지며, 깨시는 기상부터, 수유텀은 수유①부터 셉니다. 기상 카드를 눌러 기상 시각을 고칠 수 있습니다.

- **하루의 시작은 실제 기상 시각**입니다. 시작 시각에 하한은 없습니다. 프리셋의 모든 카드가 시작 시각 차이만큼 함께 움직입니다.
- **취침 상한은 그 날 루틴(프리셋)이 정한 잠든 시각, 하한은 그보다 1시간 앞**입니다. 기본 루틴은 기상 + 12시간이라 6:30 기상이면 17:30~18:30 사이에 잠들도록 맞춥니다. 입면이 19:00인 프리셋이면 18:00~19:00이 기준이 되어 프리셋대로 나옵니다.
- **낮잠은 계획하지 않고 관찰합니다.** 계획표의 낮잠 시각은 눕히는 시각과 깨우는 시각이고, 실제 길이는 기록으로 받아 그 뒤만 다시 계산합니다. 낮잠 종료가 기록되면 다음 낮잠 시작은 항상 "종료 + 그 구간 깨시(1:30 / 1:40 / 1:45 / 1:40)"입니다.
- **수유 시각은 기상 기준으로 고정**(+0:00 / +2:30 / +5:45 / +8:45)됩니다. 낮잠 중이면 낮잠 종료 10분 뒤로 밀고, 직전 수유로부터 3시간 30분을 넘길 것 같으면 그 시각에 깨우는 것으로 계획합니다(주로 낮잠②, 12:30). 낮잠이 일찍 끝나 수유까지 시간이 남으면 놀이가 들어갑니다.
- **마지막 수유는 마지막 낮잠 종료 + 프리셋의 간격**(기본 루틴은 놀이 60 + 목욕 15)을 따라가고, 입면은 그 수유 종료 10분 뒤입니다. 낮잠이 짧으면 수유와 입면도 그만큼 당겨집니다.
- **낮잠이 짧아 취침이 하한(기상+11:00)보다 이르면**: 낮잠②가 아직 안 끝났으면 105→120분으로 늘리고, 그 다음 마지막 놀이를 늘려(마지막 깨시 1:45→최대 2:00) 버팁니다. 그래도 모자라면 이른 취침을 받아들입니다. 다른 낮잠은 늘리지 않습니다.
- **낮잠이 길어 취침이 상한(기상+12:00)을 넘기면**: 마지막 놀이를 줄이고(마지막 깨시 1:45→1:30), 그 다음 낮잠④ 앞 깨시를 줄입니다(1:40→1:30, 낮잠④가 아직 시작 전일 때만). 그래도 넘으면 취침이 그만큼 늦어집니다.
- **취침이 당겨져 수유④→입면 텀이 2시간 30분에 못 미치면** 수유④를 당깁니다(낮잠③ 종료 10분 뒤, 수유③ + 2시간 30분 이후, 지금 이후 안에서). 그래도 안 되면 입면 수유텀은 2시간까지 허용합니다.
- **재계산은 지금 이후 항목만 바꿉니다.** 이미 끝난 항목은 표시하던 시각 그대로 고정하고, 진행 중인 항목은 시작 시각만 고정합니다. 단 낮잠 기록이 지난 수유 시각을 덮으면(낮잠②가 12:30까지 갔는데 수유③ 12:15가 잡혀 있던 경우) 그 수유는 낮잠 뒤로 옮깁니다.
- **낮잠 카드와 수유 카드**(수유①②③④, 수유 후 입면)를 눌러서 실제 시작·종료 시각을 기록할 수 있습니다(기본값은 계산된 시각). 시작을 바꾸면 종료가 원래 길이만큼 따라가고, 그 뒤 종료만 따로 고칠 수 있습니다. 편집기에 "시작~종료 1시간 10분" 식으로 길이가 표시됩니다. 저장하면 즉시 전체 일정이 다시 계산되고, 취소하면 버려집니다.
- 수유 시각을 기록하면 그 수유는 고정되고, **뒤 수유들은 직전 수유로부터 2시간 30분~3시간 30분 안에서** 다시 배치됩니다. 기상 시각을 기록하면 하루 시작이 그 시각으로 바뀝니다. 수유 후 입면을 기록하면 취침 상·하한 보정은 적용하지 않습니다.
- 낮잠 앞 놀이 카드와 수유 후 입면 카드에 **깨시**, 낮잠 카드에 **수면**, 수유 카드에 **수유텀**이 H:MM으로 표시됩니다.
- 메뉴의 **오늘 기록 초기화**는 오늘 일정을 완전히 지웁니다. 다른 기기에 그대로 반영됩니다. 10분 이하의 빈틈은 놀이 카드로 표시하지 않습니다.
- 하루의 경계는 자정(00:00)입니다.

## 저장소

기록과 프리셋은 Firebase Realtime Database `https://salt-planner-default-rtdb.asia-southeast1.firebasedatabase.app/salt/v5`에 저장되며, 링크를 연 모든 기기가 같은 일정을 봅니다. 15초마다, 그리고 앱을 다시 열 때마다 동기화합니다. 낮잠·수유 기록과 프리셋, 기본 루틴 지정은 나중에 고친 쪽이 반영되고 일정은 그로부터 다시 계산됩니다. 초기화나 재시작은 이전 일정을 통째로 대체합니다. 이전 경로(`/salt/v4`)의 데이터는 읽지 않습니다.

Firebase 보안 규칙:

```json
{
  "rules": {
    "salt": {
      ".read": true,
      ".write": true
    }
  }
}
```

링크를 아는 사람은 누구나 일정을 읽고 쓸 수 있습니다. 링크를 공개하지 마세요.
