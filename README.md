# 소금의 하루

아기 소금이의 하루 일과표를 기상 시각 기준으로 자동 생성하고, 수유·낮잠·기저귀·메모를 기록하는 모바일 웹앱입니다.
단일 HTML 파일이며 데이터는 브라우저 로컬 저장소(localStorage)에만 저장됩니다.

**웹앱:** https://jklim87.github.io/salt-planner/

휴대폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 사용할 수 있습니다.

## 일과표 원칙

- 취침은 항상 18:50~19:00 (입면 18:40 고정)
- 깨시(잠에서 깨서 다음 잠까지)는 85분 권장, 최대 95분
- 낮잠은 회당 2시간 미만, 마지막 낮잠은 17:25 종료
- 6:30 이전 기상은 6:30부터 계산
- 하루의 경계는 06:00. 새벽 0~6시의 밤수유·깸은 전날 "수유 후 입면" 항목에 기록
- 아침이 늦어진 만큼 낮잠 길이를 줄여 보정하고, 부족하면 낮잠 횟수를 5회 → 4회 → 3회로 줄이면서 깨시를 85 → 90 → 95분으로 늘림

## 기능

- **오늘**: 기상 시각 입력 후 시작하면 그날 시간표 자동 생성. 항목별 실제 시작/종료(±1분 버튼), 수유량(100/130/165 프리셋 + 직접 입력), 낮잠·밤잠 중 깬 시간, 기저귀(소변/지림/푸짐), 메모 기록. 상단에 밤잠·낮잠·총 수유량 요약.
- **기록**: 날짜별 요약과 항목별 실제 기록 조회.
- **내려받기**: 우상단 메뉴에서 전체 기록을 JSON 또는 CSV로 저장.
- **재계산**: 마지막 기록 시각 기준으로 남은 일정을 원칙에 맞게 다시 생성.
