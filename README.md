# 소금의 하루

아기 소금이의 하루 일과표를 기상 시각 기준으로 자동 생성하고, 수유·낮잠·기저귀·메모를 기록하는 모바일 웹앱입니다.

**웹앱:** https://jklim87.github.io/salt-planner/

휴대폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 사용할 수 있습니다.

낮잠 4회 총 5시간, 깨시 85/85/85/85/90분, 낮 수유 5회.
2026-09-11~12 실제 기록을 반영해 낮잠 길이와 수유 시점을 맞춘 값입니다.

## 일과표 원칙

- 기상 시각을 기준으로 전체 일정이 통째로 평행이동합니다. 기상이 30분 늦으면 입면도 30분 늦어집니다.
- 입면은 기상 12시간 10분 뒤 (6:30 기상이면 18:40).
- 6:30 이전 기상은 6:30부터 계산합니다.
- 하루의 경계는 06:00. 새벽 0~6시의 밤수유·깸은 전날 "수유 후 입면" 항목에 기록합니다.
- 하루 중 일정이 밀리면 메뉴의 "기록에 맞춰 남은 일정 밀기"로 실제 종료 시각과 계획의 차이만큼 이후 일정을 한 번에 조정합니다.

## 기능

- **오늘**: 기상 시각 입력 후 시작하면 그날 시간표 자동 생성. 항목별 실제 시작/종료(±1분 버튼), 수유량(100/130/165 프리셋 + 직접 입력), 낮잠·밤잠 중 깬 시간, 기저귀(소변/지림/푸짐), 메모 기록. 상단에 밤잠·낮잠·총 수유량 요약.
- **기록**: 날짜별 요약과 항목별 실제 기록 조회.
- **내려받기**: 우상단 메뉴에서 전체 기록을 JSON 또는 CSV로 저장.

## 기기 간 공유

데이터는 기본적으로 각 기기의 브라우저에만 저장됩니다. 엄마 아빠가 같은 기록을 보려면
우상단 메뉴 → "기기 간 공유 설정"에서 두 기기에 **같은 주소**를 넣으면 됩니다.

주소는 Firebase Realtime Database를 쓰며, 처음 한 번만 만들면 됩니다 (무료).

1. console.firebase.google.com 에서 프로젝트 생성
2. 빌드 → Realtime Database → 데이터베이스 만들기 (테스트 모드로 시작)
3. 데이터 탭 위쪽의 `https://...firebasedatabase.app` 주소 복사
4. 주소 끝에 남들이 모를 단어를 붙여 앱에 입력 (예: `https://xxx.firebasedatabase.app/salt-9f3a`)

주소를 아는 사람은 누구나 읽고 쓸 수 있으므로, 추측하기 어려운 단어를 쓰고 주소를 공유하지 마세요.
항목 단위로 나중에 수정한 쪽이 반영되며, 15초마다 그리고 앱을 다시 열 때마다 동기화합니다.
