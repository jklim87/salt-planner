# 소금의 하루

아기 소금이의 오늘 일정표입니다. 기상 시각을 넣고 시작하면 하루 일정 15개가 자동으로 만들어지고, 링크를 연 모든 기기가 같은 일정을 봅니다.

**웹앱:** https://jklim87.github.io/salt-planner/

휴대폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 사용할 수 있습니다.

|---|---|---|
| 06:30~06:45 | 기상 후 수유 | |
| 06:45~07:55 | 놀이 | 깨시 85분 |
| 07:55~09:40 | 낮잠① 105분 | |
| 09:45~10:00 | 수유 | |
| 10:00~11:05 | 놀이 | 깨시 85분 |
| 11:05~12:30 | 낮잠② 85분 | |
| 12:35~12:50 | 수유 | |
| 12:50~13:55 | 놀이 | 깨시 85분 |
| 13:55~15:00 | 낮잠③ 65분 | |
| 15:10~15:25 | 수유 | |

항목은 이 15개로 고정이며 추가·삭제할 수 없습니다.

## 동작 규칙

- **기상이 늦으면 전체 일정이 그만큼 뒤로 밀립니다.** 6:40 기상이면 모든 항목이 10분씩 늦어집니다. 6:30 이전 기상은 6:30으로 계산합니다.
- **입면이 19:00을 넘기면** 아래 순서로 줄여서 19:00에 맞춥니다. 앞 규칙의 하한까지 다 쓴 뒤 다음으로 넘어갑니다.
  1. 마지막 깨시 90분 → 85분
  2. 낮잠① 105분 → 90분
  3. 낮잠③ 65분 → 60분
  4. 낮잠④ 45분 → 40분
- **입면이 18:30보다 이르면** 아래 순서로 늘려서 18:30에 맞춥니다.
  1. 낮잠② 85분 → 100분
  2. 낮잠③ 65분 → 70분
  3. 낮잠④ 45분 → 50분
- 이미 지난 항목은 줄이거나 늘리지 않습니다.
- **낮잠 카드만** 눌러서 실제 시작·종료 시각을 기록할 수 있습니다(기본값은 계산된 계획 시각). 저장을 눌러야 반영되고, 취소하면 버려집니다.
- 낮잠 앞 놀이 카드와 수유 후 입면 카드에는 **깨시**(직전 잠 종료부터 다음 잠까지)가 표시됩니다. 실제 시각이 기록되어 있으면 그 값으로 계산합니다.
- 메뉴의 **일정 재계산**은 실제 시각이 기록된 마지막 항목(낮잠이 끝났으면 그 종료 시각)을 기준으로 뒤 일정을 다시 배치하며 위 규칙을 적용합니다.
- 메뉴의 **오늘 기록 초기화**는 오늘 일정을 완전히 지우고 시작 화면으로 돌아갑니다. 다른 기기에도 그대로 반영됩니다.
- 하루의 경계는 자정(00:00)입니다.

## 저장소

기록은 Firebase Realtime Database `https://salt-planner-default-rtdb.asia-southeast1.firebasedatabase.app/salt/v3`에 저장되며, 링크를 연 모든 기기가 같은 일정을 봅니다. 15초마다, 그리고 앱을 다시 열 때마다 동기화합니다. 항목 단위로 나중에 고친 쪽이 반영되고, 초기화나 재시작은 이전 일정을 통째로 대체합니다.

Firebase 보안 규칙:

```json
{
  "rules": {
    "salt": {
      ".read": true,
      ".write": true
    }
  }
}
```

링크를 아는 사람은 누구나 일정을 읽고 쓸 수 있습니다. 링크를 공개하지 마세요.
