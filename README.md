# 소금의 하루

아기 소금이의 오늘 일정표입니다. 기상 시각을 넣고 시작하면 하루 일정 15개가 자동으로 만들어지고, 링크를 연 모든 기기가 같은 일정을 봅니다.

**웹앱:** https://jklim87.github.io/salt-planner/

휴대폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 사용할 수 있습니다.

## 동작 규칙

- **수유 시각은 기상 시각 기준으로 고정**됩니다. 6:45에 일어나면 모든 수유가 15분씩 밀리고 텀은 그대로입니다. 다른 규칙 때문에 수유를 옮겨야만 할 때는 직전 수유로부터 **최소 2시간 30분, 최대 3시간 30분** 안에서만 옮깁니다.
- **낮잠은 깨시 85분을 유지**합니다. 깨시는 직전 잠(기상 또는 낮잠)이 끝난 시각부터 다음 낮잠 시작까지입니다. 낮잠이 일찍 끝나면 다음 낮잠도 그만큼 당겨집니다(그 앞 수유가 끝난 뒤에만).
- 낮잠이 일찍 끝나 수유까지 시간이 남으면 그 사이에 **놀이가 자동으로 들어갑니다.**
- **수유 후 입면은 낮잠④ 종료 + 60분**을 따라갑니다. 입면이 19:00을 넘기면 마지막 깨시 90→85, 낮잠① 105→90, 낮잠③ 65→60, 낮잠④ 45→40 순으로 줄이고, 18:30에 못 미치면 낮잠② 85→100, 낮잠③ 65→70, 낮잠④ 45→50 순으로 늘립니다. 그래도 모자라면 입면이 그만큼 당겨집니다.
- 실제 기록(낮잠·수유)이 있는 마지막 항목보다 앞의 낮잠과 이미 끝난 낮잠은 길이를 바꾸지 않습니다.
- 6:30 이전 기상은 6:30으로 계산합니다.
- **낮잠 카드와 수유 카드**(기상 후 수유, 수유②③④, 수유 후 입면)를 눌러서 실제 시작·종료 시각을 기록할 수 있습니다(기본값은 계산된 시각). 저장하면 즉시 전체 일정이 다시 계산되고, 취소하면 버려집니다.
- 수유 시각을 기록하면 그 수유는 고정되고, **뒤 수유들은 직전 수유로부터 2시간 30분~3시간 30분 안에서** 다시 배치됩니다. 기상 후 수유 시각을 기록하면 하루 시작이 그 시각으로 바뀝니다. 수유 후 입면을 기록하면 18:30~19:00 보정은 적용하지 않습니다.
- 낮잠 앞 놀이 카드와 수유 후 입면 카드에 **깨시**가 표시됩니다.
- 메뉴의 **일정 재계산**은 기록된 낮잠 시각으로 일정을 다시 만들고, **오늘 기록 초기화**는 오늘 일정을 완전히 지웁니다. 두 기능 모두 다른 기기에 그대로 반영됩니다.
- 하루의 경계는 자정(00:00)입니다.

## 저장소

기록은 Firebase Realtime Database `https://salt-planner-default-rtdb.asia-southeast1.firebasedatabase.app/salt/v4`에 저장되며, 링크를 연 모든 기기가 같은 일정을 봅니다. 15초마다, 그리고 앱을 다시 열 때마다 동기화합니다. 낮잠·수유 기록은 나중에 고친 쪽이 반영되고 일정은 그로부터 다시 계산됩니다. 초기화나 재시작은 이전 일정을 통째로 대체합니다.

Firebase 보안 규칙:

```json
{
  "rules": {
    "salt": {
      ".read": true,
      ".write": true
    }
  }
}
```

링크를 아는 사람은 누구나 일정을 읽고 쓸 수 있습니다. 링크를 공개하지 마세요.
