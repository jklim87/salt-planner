기기 간 공유

엄마 아빠 휴대폰에 같은 주소를 넣으면 기록이 실시간으로 함께 보여요. 비워두면 이 기기에만 저장됩니다.

주소 만드는 법 (처음 한 번, 무료)
  1. console.firebase.google.com 에서 프로젝트 생성
  2. 빌드 → Realtime Database → 데이터베이스 만들기
  3. 보안 규칙은 "테스트 모드로 시작"
  4. 규칙 탭에서 ".read": true, ".write": true 확인
  5. 데이터 탭 위쪽 주소(https://...firebasedatabase.app) 복사
  6. 주소 끝에 /소금 처럼 남들이 모를 단어를 붙여 위에 붙여넣기
